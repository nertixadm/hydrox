Hydrox - анализатор личных Telegram-чатов

Что это

Hydrox - локальный инструмент для анализа переписки между двумя людьми в Telegram. Работает полностью на вашем компьютере, данные никуда не отправляются. Позволяет получить глубокую статистику и сгенерировать визуальные слайды в стиле Wrapped.

Установка

1. Установите Python 3.10 или новее.
2. Клонируйте проект:
   git clone <url> hydrox
   cd hydrox

3. Создайте виртуальное окружение:
   python -m venv .venv
   source .venv/bin/activate
   (Windows: .venv\Scripts\activate)

4. Установите зависимости:
   pip install -r requirements.txt

5. Запустите:
   streamlit run app.py

6. Откройте в браузере http://localhost:8501

Экспорт чата из Telegram

1. Откройте Telegram Desktop.
2. Настройки - Продвинутые - Экспорт данных.
3. Выберите чат, отметьте "Сообщения".
4. Формат: JSON (не HTML).
5. Сохраните result.json.

Использование

1. В сайдбаре нажмите "Загрузите JSON-экспорт чата" и выберите result.json.
2. Настройте фильтры:
   - Период: даты начала и конца анализа.
   - Пользователи: оставьте обоих или выберите одного.
   - Лимит сообщений: для ускорения на больших чатах.
   - Топ-N слов: глубина анализа частотности.
   - Прогноз: горизонт в днях.
   - Сервисные записи: включать звонки и подарки или нет.

3. Переключайтесь между 15 вкладками для детального изучения:
   - Общая статистика: основные метрики.
   - Качество данных: проверка целостности.
   - Участники: профили собеседников.
   - Реакции: разбор по типам.
   - Активность: графики по часам и дням.
   - Частотные слова и биграммы: лексика чата.
   - Сессии: периоды непрерывного общения.
   - Длина текстов и темп диалога: стиль переписки.
   - Ежедневная и месячная статистика: динамика.
   - Сервисные записи: звонки, редактирования.
   - Сравнение: head-to-head двух участников.
   - Прогноз: тренд активности.

Итоги чата

В сайдбаре нажмите "Создать Итоги чата". Сгенерируются 9 слайдов размером 1080x1920:
1. Титульный: имена, период, общее число сообщений.
2. Кто пишет больше: сравнение с процентами.
3. Главные слова: топ-5 каждого участника.
4. Время в чате: часы общения и креативные сравнения.
5. Пик активности: самый активный час.
6. Активный день: день недели с максимумом.
7. Самый длинный диалог: дата, время, длительность.
8. Ночная активность: сообщения с 23:00 до 05:00.
9. Финальный: сводка метрик.

Скачайте все слайды одним ZIP-архивом.

Настройка

Файл config.yaml содержит параметры:
- colors: цвета для участников.
- analysis: пороги сессий, топ-слов, стоп-слова.
- plots: цветовая схема тепловой карты.
- wordcloud: параметры облака слов.

Стоп-слова можно редактировать напрямую в config.yaml.

Приватность

Все данные обрабатываются локально. Приложение слушает только localhost:8501. Никакие файлы не загружаются на внешние серверы.
