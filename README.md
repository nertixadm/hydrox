# Анализ чата Telegram

Интерактивное приложение для анализа JSON-экспорта переписки Telegram с возможностью генерации подробного PDF-отчёта в тёмном стиле.

## Возможности
- Загрузка JSON-экспорта (любой размер)
- 15 интерактивных вкладок:
  - Общая статистика, качество данных, участники, реакции
  - Активность по часам, дням, тепловая карта
  - Частотные слова (топ-N), биграммы, облака слов
  - Сессии, длина текстов, темп диалога
  - Ежедневная и месячная статистика
  - Сервисные записи и звонки
  - Сравнение двух пользователей
- Гибкие фильтры по датам и пользователям
- Скачивание PDF-отчёта с нумерацией рисунков и полной аналитикой
