# Hydrox

Локальное приложение для анализа личных чатов Telegram. Hydrox строит статистику переписки, показывает активность участников и может создать набор вертикальных слайдов в стиле Wrapped.

## Что умеет

- Загружать JSON-экспорт чата из Telegram Desktop.
- Показывать общую статистику, активность по часам и дням, реакции, медиа, ответы и редактирования.
- Анализировать слова, биграммы, интервалы между сообщениями и сессии общения.
- Строить ежедневную и месячную динамику, а также краткосрочный прогноз активности.
- Учитывать подарки и звонки, если они есть в экспорте.
- Генерировать девять слайдов «Итоги чата» и скачивать их одним ZIP-архивом.

## Требования

- Python 3.10 или новее.
- Telegram Desktop для экспорта истории чата.

## Установка и запуск

```bash
git clone https://github.com/nertixadm/hydrox.git
cd hydrox

python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

streamlit run app.py
```

В Windows активация окружения выглядит так:

```powershell
.venv\Scripts\activate
```

После запуска откройте в браузере адрес, который покажет Streamlit. Обычно это `http://localhost:8501`.

## Как экспортировать чат из Telegram

1. Откройте Telegram Desktop.
2. Перейдите в настройки и выберите экспорт истории чата.
3. Выберите нужный чат и включите пункт «Сообщения».
4. Укажите формат **JSON**, не HTML.
5. Дождитесь завершения экспорта и найдите файл `result.json`.
6. Загрузите этот файл в боковой панели Hydrox.

## Работа с приложением

После загрузки экспорта настройте в боковой панели:

- период анализа;
- одного или нескольких участников;
- лимит сообщений для больших чатов;
- размер топа слов;
- горизонт прогноза;
- включение сервисных записей в ежедневную статистику.

Для «Итогов чата» выберите ровно двух пользователей и нажмите кнопку в боковой панели. Будет создано девять PNG-слайдов размером 1080×1920:

1. Титульный с периодом и числом сообщений.
2. Сравнение активности участников.
3. Главные слова.
4. Оценка времени общения.
5. Пиковый час активности.
6. Самый активный день недели.
7. Самый длинный непрерывный диалог.
8. Ночная активность.
9. Итоговая сводка.

## Настройка

Параметры находятся в [config.yaml](config.yaml):

- `colors` — цвета участников и интерфейса;
- `analysis` — пороги сессий, стоп-слова и размеры топов;
- `plots` — настройки графиков.

Стоп-слова можно редактировать прямо в `config.yaml`.

## Приватность

При локальном запуске экспорт обрабатывается в памяти браузерного сеанса приложения и не записывается Hydrox во временные файлы. Не загружайте личные переписки в публичные экземпляры приложения, если не уверены в их политике обработки данных.

## Версии и Git

Git сохраняет историю изменений в виде коммитов. Готовый релиз удобно отмечать тегом: например, `v0.1.1-alpha`.

```bash
git status
git add app.py hydrox.py config.yaml README.md requirements.txt .gitignore
git commit -m "Краткое описание изменения"
git tag -a v0.1.1-alpha -m "Alpha 1.1"
```

Полезные команды:

```bash
git log --oneline          # история коммитов
git tag -l                 # все отмеченные версии
git tag --points-at HEAD   # тег текущего коммита
```

Если настроен удалённый репозиторий на GitHub, отправьте коммит и тег:

```bash
git push origin HEAD
git push origin v0.1.1-alpha
```
